# Football Shorts

Windows компьютері үшін футбол видеосынан шортс жасайтын Python бағдарламасы.
YouTube сілтемесі → автоматты талдау → гол/slow motion → MP4 және YouTube TXT.

## Орнату

[Releases](https://github.com/ttexasfromkz-web/footshorts/releases/latest) ішінен
`FootballShorts-Setup.exe` жүктеп, іске қосыңыз. Python мен кітапханалар бірге орнатылады;
оларды бөлек орнатудың қажеті жоқ. Жұмыс үстеліндегі Football Shorts белгішесімен ашыңыз.
Бағдарлама кітапханаларды тексереді; ақау болса, бөлек ортаға жөндейді (жөндеуге интернет керек).
Start мәзіріндегі «Football Shorts - Repair» арқылы да тексеруге болады.

Бұрынғы ZIP нұсқасы да қолжетімді: Python 3.11 (64-bit), `1_INSTALL.bat`, кейін `2_START.bat`.
Қолданыстағы `output`, музыка мен жоба файлдарын сақтаңыз. Жаңа EXE бөлек папкаға орнатылса,
бұрынғы жобалар сол ескі папкада қалады; оларды жаңа папканың `output` ішіне көшіруге болады.

## Автоматты жаңарту

Бағдарлама GitHub Releases ішіндегі жаңа нұсқаны ашылғанда тексереді.
Жаңарту табылса, жаңа нұсқаның нөмірін көрсетіп, «Жаңартайын ба?» деп сұрайды.
«Иә» таңдағаннан кейін ғана жүктеп, SHA256 және файл тізімін тексереді.
«Жоқ» таңдасаңыз, ағымдағы нұсқамен жалғастырасыз. Орнату басталған жұмыстың аяқталуын күтеді.
Бағдарлама жабылып қайта ашылады. Жаңа нұсқа іске қосылмаса, бұрынғы код қалпына келеді.
`output`, `music`, `.venv`, `ui_state.json` жаңарту пакетіне кірмейді.
Тәуелділіктер өзгермесе, кітапханалар қайта жүктелмейді. Өзгерсе, бөлек орта орнатылады.

## Жаңа нұсқа шығару

1. Кодты өзгертіп, `version.json` ішіндегі нұсқаны өсіріңіз, мысалы `1.5.1`.
2. Тесттер: `python -m unittest discover -p "test_*.py" -v`.
3. Өзгерістерді main тармағына commit/push етіңіз (немесе жаңа нұсқа тегін push етіңіз).
4. GitHub Actions Windows-та тесттерді жүргізіп, EXE орнатқышын тексеріп, ZIP пен update.json жасап, Release шығарады.
   Сол Release жарияланғаннан кейін компьютердегі бағдарламалар жаңаруды көреді.

main тармағында version.json өзгергенде Release автоматты құрылады.
Нұсқа өзгермесе, жай код push ету Release шығармайды. Жаңа тег не release workflow да қолдануға болады.
Release workflow-ға repository contents write рұқсаты қажет; ол workflow ішінде берілген.

Толық қазақша нұсқаулық: [README_KZ.md](README_KZ.md).
Тексерудің көлемі мен шектеулері: [VALIDATION.md](VALIDATION.md).
Автоматты іріктеу және OCR мінсіз емес: дайын видеоны жарияламас бұрын көріп тексеріңіз.


## Видеоны тексеру және кезек

«Видеоны көру және өңдеу» арқылы бастапқы видео мен дайын нәтижені бағдарлама
ішінде ойнатыңыз. Үзінді шекарасын түзету, өшіру, голды белгілеу, камера нүктелері
мен үлкейту бар. Өзгерісті сақтап, бастапқы материалдан қайта экспорттай аласыз.

«Бірнеше сілтеме → кезекпен өңдеу» әр матчты жеке папкаға жасайды.
Қате тапсырмадан кейін келесісін жалғастырады; кезек queue.json ішінде сақталады.
